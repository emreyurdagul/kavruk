# Kavruk

Nitelikli kahve kavurucusu için konsept e-ticaret sitesi (kurgusal marka).

- Kavrum eğrisi: bitiş noktasını sürükleyince çekirdek rengi, tat notaları ve demleme önerisi değişir (klavye ile de kullanılabilir)
- Haftalık kavrum rafı: öğütme ve paket seçimi, sepete ekleme
- Sepet çekmecesi: adet, ücretsiz kargo eşiği, toplam
- Kafeler için toptan talep formu, doğrulamalı

React 19 + TypeScript + Vite. `npm run dev`
